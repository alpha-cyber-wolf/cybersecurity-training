# Cybersecurity Training

Training notes, lab plans, and learning resources for cybersecurity.

## Status

This repository is an initial scaffold. Exercises will be added as they are prepared and reviewed. No live targets, credentials, or client material belong here.

## Learning approach

- Use isolated, intentionally vulnerable lab environments.
- Define learning goals, prerequisites, and cleanup steps for each exercise.
- Keep examples defensive, authorized, and suitable for the stated audience.
- Explain how to verify results and where an exercise is limited.

## Planned material

- Introductory security concepts and glossaries
- Safe lab instructions and exercises
- Digital forensics learning notes
- Instructor checklists and learner resources

Do not run exercises against systems without explicit authorization. Do not post personal data, credentials, confidential case details, or real target information.

## Contributions

Training contributions should include learning objectives, setup requirements, expected outcomes, and safe cleanup instructions.
